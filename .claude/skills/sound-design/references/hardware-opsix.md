# Korg opsix

Marks: [M] read in the manual, [S] other source, [J] judgement, [U] unverified. No opsix was attached when this was written, so nothing here has been tried on one.

Sources for [M]:
- Owner's Manual E6, covering opsix, SE and module: downloads at https://www.korg.com/us/support/download/product/0/874/ (PDF https://cdn.korg.com/us/support/download/files/dc109944c32fd473b555fee28318cf8d.pdf). Page numbers are the manual's.
- MIDI Implementation Chart in that manual, version 3.1.0, 2023-01-17 (p.116).

Which model? The mk II "is operated in the same way" and differs in polyphony, 64 voices against 32, per Korg's note: https://cdn.korg.com/us/support/download/files/2a1f60b7620f1ddd986b2fcf590c0ce6.pdf. Only the SE sends aftertouch. [M chart note 4]

## USB and audio

- "A class-compliant USB-MIDI device, and requires no driver for basic MIDI functionality." [M p.95]
- USB carries MIDI and data; the manual describes no USB audio. Its diagrams send the audio from OUTPUT L/MONO and R to an audio interface. [M p.16-17, p.95] **So it needs an audio interface, or a cable into the Syntakt's inputs.**
- SYS page, USB Network: set NCM on a Mac (macOS 11 or later), RNDIS on Windows; needs a restart. [M p.82] It's for the computer link, not audio.
- The Sound Librarian (Mac 1.3.0) needs USB. [M p.95; S: the download page]

## Settings to change

SHIFT + EFFECT opens GLOBAL; PAGE < > to MIDI; OP SELECT +/- to choose; DATA ENTRY C or F to change. [M p.97]

| Setting | To | Why |
|---|---|---|
| Global Channel | e.g. 2 | sets the channel for notes, bend and CC [M p.76] |
| Rx CC | on | otherwise CC is ignored, apart from CC1, CC64 and 120 upward [M p.78] |
| Rx Prog Chg | on | to choose programs from a script |
| Rx Pitch Bend | on | |
| Clock | Off for one-shots, Auto or Extern when a script is the clock | Auto falls back to internal after 500 ms without clock [M p.77] |
| Rx Transport | on, if using Start/Stop | |
| Local Control | Off if something echoes MIDI back | stops double notes [M p.98] |
| Convert Position | Pre | so Transpose and the velocity curve don't touch incoming MIDI. Post applies them to it [M p.77-78] |

## Parameters

Chart 3.1.0 [M p.116]. **There is no NRPN in the chart.** Everything named on the panel is 7-bit CC.

| CC | Parameter | CC | Parameter |
|---|---|---|---|
| 0, 32 | Bank select MSB, LSB | 71 | Filter resonance |
| 1 | Mod wheel | 73 | Attack (Home/Algorithm page) |
| 5 | Glide time | 74 | Filter cutoff |
| 7 | Volume | 79 | Decay/Release (Home) |
| 10 | Pan | 81, 82, 83 | FX1, FX2, FX3 first parameter |
| 11 | Expression | 102-107 | OP1-6 level sliders |
| 64 | Damper | 108-113 | OP1-6 ratio knobs |
| 65 | Glide mode | 1-119 | usable as Virtual Patch sources |
| 66, 67 | Sostenuto, soft | 1-119 | transmittable from the Motion Sequencer |
| 70 | Algorithm | 120, 121 | All sounds off, reset controllers |

- Notes on any channel 1-16 as set; note-off velocity is clipped at 64 received. Poly and channel aftertouch received, as Virtual Patch sources. Pitch bend yes.
- Program change 0-99 with bank select. [M chart] The mapping of banks to its programs isn't in what was read; find it by experiment or read back via the librarian. [U]
- **Anything else goes through a Virtual Patch.** Twelve routings per program, with sources and destinations in lists at p.88-89, and CC 1-119 as sources. So a program can be made with, say, CC 20 going to OP3 feedback, and then it's playable from a script. That's a per-program edit done by hand on the panel. [M p.71, chart]
- Sysex: universal device inquiry, master volume, master fine and coarse tuning; MIDI 2.0 Property Exchange. [M chart notes 3, 5] It can load first-generation DX7 sysex, but only whole 32-voice banks, 4,104 bytes [M p.99]. So, as a judgement rather than anything Korg says, patches could be generated by script and loaded as a DX7 bank, for the plain FM part of it (no altered modes). Korg publishes the Property Exchange implementation: https://www.korg.com/us/support/download/manual/0/874/5488/ (not read in detail here). [U]

## Tuning

The manual describes master tune (±50 cents), transpose, and per-operator pitch: RATIO (coarse, fine, plus ±1 octave transpose, plus detune in one-cent steps) or FIXED (0.01 to 9999.99 Hz). [M p.50-51, p.76] It documents no scale or microtuning table (searched for "micro", "scale", "tuning", "temperament"). Master Fine Tuning sysex would retune the whole instrument, and pitch bend retunes a mono line.

What FIXED gives you is better for this job than a scale: operators that don't follow the keyboard, so the partials stay put and inharmonic while the note moves. [J]

## Engines

Six operators, 40+ preset algorithms plus user algorithms. Each operator has a mode: [M p.7-10, p.43-49]

| Mode | What happens | Params | Factory example | Use it for [J] |
|---|---|---|---|---|
| FM | phase modulation, as in DX synths | FB, WIDTH. Feedback passes "complex noise" above 75% | 327 2OP FM | bells, glass, metal, sub with a bright attack |
| Ring Mod | multiplies by the modulators; a rectifier adds overtones | DEPTH, SHAPE | 134 Ring It On, 331 | alarms, tanks ringing, inharmonic speech |
| Filter | keytracked filter over osc and modulators; cutoff follows the operator's pitch | TYPE, CUTOFF, RESO, OSC MIX | 178 Formant Pad, 324 Reso Noise | resonant noise, whooshes that track pitch |
| Filter FM | modulators sweep the cutoff at audio rate | TYPE, CUTOFF, RESO | 157, 335 | tearing, vocal, snarling; the creature |
| Wave Folder | folds the wave at a threshold | GAIN, BIAS, OSC MIX | 024 Dynamik, 334 | hard harmonics that bloom under velocity or an envelope; aggressive leads |
| Effect | the operator is an effect: Peak EQ, Shelf EQ, Phaser, Short Delay, Comb, Distortion, Drive, Decimator, Waveshaper, Punch | varies | 237 Cinematic FB Doom, 313 Cockpit Emergency, 311 KONG's Footstep | a per-voice comb or decimator in the algorithm |
| Bypass, Mute | for building patches | | | |

Filter types in operators: LPF, HPF, BPF, BRF, MG LPF12/24, MG HPF12/24, MG BPF6/12, MS-20 LPF/HPF. [M p.44-45] Global filter adds LPF Poly6 and others, self-oscillating types included. [M p.58]

Waves: Sine, Sine 12bit and 8bit, Tri, Saw and Saw HD, Square and Square HD, additive tables (Saw3, Sqr3, Tri3, 12345, 1+2 to 1+8), Noise S/H, White, Pink, Blue. [M p.84] Sine 8bit is a ready-made lo-fi FM. [J]

Effects, three slots (FX1-3): 30 types including Decimator, Grain Shifter, Shimmer Reverb, Spring Reverb, Tape Echo, Guitar Amp, Master Limiter. [M p.105] Grain Shifter is the nearest thing to granular in this rig. [J]

Also: step sequencer (16 steps, 6 notes per step), motion sequencer (6 lanes), randomised editing for patches. [M p.24-34, p.105]

Polyphony 32 voices (mk II 64), depending on settings. [M, S above]

Best at: anything that needs inharmonic, metallic, glassy or precisely timed spectra. It's the sound of the machines here.
